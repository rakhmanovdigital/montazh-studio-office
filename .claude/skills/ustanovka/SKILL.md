# Установка — карточками, по одной

## Правила (железные)

1. **Только из списка** `studio/ustanovka.md`. Чего там нет — не ставим. Новое попадает в
   список только через навык `razvedchik` (проверка) + её «да».
2. **Только официальные источники:** Homebrew, сайт производителя, магазин Chrome.
   Никаких `curl … | bash`, никаких архивов из чужих инструкций.
3. **Одна программа — одна карточка — одно «да».** Без «да» не ставишь.
4. **Пароль вводит она сама** — в окне мака или в установщике. Ты пароль не видишь и не просишь.
5. **После установки — проверка** (команда из таблицы ниже), только потом ✅ в списке и
   строка в «Журнал установки». «Поставилось» ≠ «работает».
6. **Не встало** → спокойно объясни причину, дай ОДИН шаг. Два раза не вышло → ⏸ и дальше.
7. **Напоминание** приходит от хука в начале дня строкой `[установка]`. Скажи одной строкой
   (что это + зачем + «поставим сейчас или позже?»). «Позже» → ⏸, не повторять сегодня.
8. **Ставь, когда нужно.** «Потом»-программы предлагай, только когда её задача их требует:
   «для озвучки нужна одна программа — вот карточка».

## Карточка (форма — всегда эта)

> **🧰 <Название>**
> **Что это:** <одна бытовая фраза>
> **Зачем тебе:** <на её работе — что станет можно>
> **Что будет:** <сколько минут, что появится на экране>
> **Твои руки:** <ничего / нажать «Установить» / ввести пароль от мака>
> Ставим?

## Порядок и как ставить

Сначала `bash scripts/proverka.sh` — уже стоящее пропускаем (и сразу ✅).

| # | Что | Как ставить | Проверка |
|---|---|---|---|
| 1 | Инструменты Apple | `xcode-select --install` → всплывёт окно Apple, она жмёт «Установить», ждёт 5–15 мин | `xcode-select -p` |
| 2 | Homebrew | `open https://github.com/Homebrew/brew/releases/latest` → она качает файл `Homebrew-….pkg`, открывает, жмёт «Продолжить», вводит пароль мака. Потом ты: `echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile` | `/opt/homebrew/bin/brew --version` |
| 3 | FFmpeg | `brew install ffmpeg` (5–10 мин, она ничего не делает) | `ffmpeg -version` |
| 4 | Python | уже пришёл с инструментами Apple | `python3 --version` |
| 5 | Google Chrome | если нет: `open https://www.google.com/chrome/` → она качает и перетаскивает в «Программы» | `bash scripts/proverka.sh` |
| 6 | Шрифты | `brew install --cask font-montserrat font-inter font-bebas-neue font-unbounded` | `bash scripts/proverka.sh` |
| 7 | yt-dlp | `brew install yt-dlp` | `yt-dlp --version` |
| 8 | Расширение Claude для Chrome | `open https://claude.ai/chrome` → она жмёт «Установить» в магазине Chrome и входит в свой Claude. **Перед этим** объясни разрешения: расширение видит страницы, которые ты ему открываешь, — поэтому рабочие банки и почту при нём не открываем | она видит значок Claude в Chrome |
| 9 | Запасной Инстаграм | объясни: «Инстаграм отдаёт ролики только тем, кто вошёл. Заводим запасной аккаунт, который не жалко». Она сама входит в него в Chrome. Свой рабочий и клиентские — **никогда**. При первом скачивании мак спросит доступ к «Chrome Safe Storage» — это yt-dlp берёт вход из браузера, жать «Разрешить» | первое скачивание в `razvedchik` прошло |
| 10 | Deepgram + ключ | навык `klyuchi` | `python3 -I scripts/klyuchi.py proverit` |
| 11 | Тестовый ролик | `python3 -I scripts/montazh.py --test` | файл открылся у неё |

**«Потом»-программы:**
- **Google Cloud** (Gemini смотрит ролик целиком). Регистрация на `cloud.google.com` — она
  сама, с картой. Объясни ДО: «карта нужна для проверки. Даётся $300 подарочных на 90 дней.
  Денег не списывают, пока ты сама не нажмёшь Upgrade — эту кнопку мы не нажимаем никогда».
  Потом: `brew install --cask google-cloud-sdk` → `gcloud auth login` (она входит в браузере)
  → `gcloud config set project <id проекта>` → в консоли включить Vertex AI API.
  Отметь дату окончания кредитов в `studio/ustanovka.md` — напоминай за 2 недели.
  Честно: ролики, которые отдаём Gemini, уходят в Google — она решает, какие можно.
- **ElevenLabs** — ключ в сейф (`ELEVENLABS_API_KEY`), навык `klyuchi`.
- **Telegram-бот** — ключ в сейф (`TELEGRAM_BOT_TOKEN`), навык `klyuchi`.

- Ей: «✅ <Название> — это наш <бытовая роль>. Если непонятно, что это и зачем, — спрашивай.»
