# Ключи и сейф

## Железные правила

- Ключ **никогда** не просим в чат и не повторяем, если он туда попал.
- Помощник **не читает** `.env` (запрещено в настройках) и не печатает ключи. Скрипты берут сами.
- Ключ вставляет **она**, своими руками, в открытый ей файл.
- Ключ попал в чат → «ничего страшного» → помоги удалить его на сайте сервиса и сделать новый.

## Сейф руками (практика)

1. Создать сейф из шаблона, если его нет (ключей в шаблоне нет — только названия):
   `[ -f .env ] || cp env-shablon.txt .env`
2. Объясни: «Файл называется `.env`. Точка в начале делает его невидимым в Finder — это
   специально, чтобы его случайно не отправили. Я открою его тебе в текстовом редакторе.»
3. Открыть ей: `open -e .env` (откроется в «Тексте»/TextEdit).
4. Она: находит строку `DEEPGRAM_API_KEY=` → ставит курсор сразу после `=` → Cmd+V → Cmd+S.
   Пробелов и кавычек не нужно.
5. Проверка: `python3 -I scripts/klyuchi.py proverit` — показывает только ✅/❌ по каждому
   сервису, без ключей.
6. Хочет увидеть сейф в Finder: `open -R .env` (или в Finder Cmd+Shift+. показывает скрытые файлы).

Новый сервис → добавь строку-название в сейф без значения, не читая файл:
`grep -q '^ИМЯ_КЛЮЧА=' .env || echo 'ИМЯ_КЛЮЧА=' >> .env` — и снова открой ей.
(Добавь то же имя в `env-shablon.txt`, чтобы шаблон помнил.)

## Как объяснять (картинки)

- **API** — окошко выдачи на кухне ресторана: офис подаёт заказ, сервис отдаёт готовое.
- **Ключ** — карта-пропуск к окошку; по ней сервис знает, что это ты, и списывает с твоего счёта.
- **Сейф `.env`** — ящик с пропусками в твоей квартире; в интернет не выносится.
- **Подарочные доллары** — предоплаченный счёт: кончатся — сервис просто перестанет
  отвечать, сам с карты ничего не спишет (если не нажимать Upgrade / не включать автооплату).

## Что открывают ключи (примеры для фантазии)

| Сервис | Что офис сможет |
|---|---|
| Deepgram | голос → текст по словам: караоке-субтитры, расшифровка созвонов с клиентом |
| Google Cloud (Gemini, Veo) | смотреть ролик целиком со звуком; оживлять фото в видео; генерировать картинки |
| ElevenLabs | живой голос диктора, озвучка на других языках |
| Telegram-бот | писать тебе: «ролик клиента готов, вот превью» |
| Google Диск | забирать исходники из папки клиента и класть готовое обратно |
| Notion / Google Таблицы | вести учёт пакетов: сколько роликов сдано, сколько осталось |

Главная мысль: «Почти у любого сервиса есть такой пропуск. Хочешь, чтобы офис что-то
умел, — спроси: а есть ли у этого сервиса ключ?»
