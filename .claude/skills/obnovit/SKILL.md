# Обновление офиса

Её данные (клиенты, профиль, доска, правки, память, сейф, медиа) живут в файлах, которых
нет в репозитории автора — обновление их не трогает. Обновляются только «шаблонные» файлы:
навыки, скрипты, шаблоны, характеры сотрудников.

1. Снимок: `git add -A && git commit -qm "снимок перед обновлением" || true`
2. Что нового: `git fetch origin` → `git log --oneline HEAD..origin/main` — перескажи ей
   простыми словами (2–5 строк). «Обновляем?»
3. «Да» → `git merge --no-edit origin/main`.
4. Конфликт (она меняла тот же шаблонный файл) → `git merge --abort`, объясни, какой файл,
   и предложи: оставить её версию или взять новую. Ничего не решай за неё.
5. После: `bash scripts/proverka.sh` и `python3 -I scripts/montazh.py --test` — студия жива.

Офис только скачивает. Отправлять что-то на GitHub (push) запрещено в настройках.
