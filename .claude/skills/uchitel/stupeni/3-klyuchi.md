# Ступень 3 — Ключи и сейф

Цель: она понимает, что такое API-ключ и сейф `.env`, сама положила ключ Deepgram, и у неё
расширилось представление «что офис может подключить». Механика — навык `klyuchi`.

## Ход (по шагу)

1. **Картинка «кухня и окошко».** «Есть сервисы, которые умеют что-то очень хорошо. Deepgram
   — переводит голос в текст. Представь кухню ресторана: офис туда не заходит, он подаёт
   заказ в окошко — „вот голос, сделай текст“. Это окошко называется API.»
2. **Ключ.** «Чтобы окошко приняло заказ, нужна карта-пропуск — это ключ. По нему сервис
   понимает, что заказ твой, и списывает с твоего счёта. Поэтому ключ — как ключ от квартиры:
   никому не показываем, в чат не кидаем, в интернет не выкладываем.»
3. **Сейф.** «Ключи живут в сейфе — это файл `.env` в папке офиса. Внутри строчки
   „НАЗВАНИЕ = ключ“. Офис сам берёт оттуда, когда нужно. В интернет этот файл не уезжает
   никогда — это встроено в защиту.»
4. **Регистрация в Deepgram — веди за руку**, по шагу: открой сайт (`open https://console.deepgram.com/signup`)
   → «нажми Sign up, войди через Google или почту — пароль вводишь сама» → «что видишь на
   экране?» → подарочные доллары на старте: «это на много часов расшифровки».
   Найти ключ: в консоли Deepgram раздел API Keys → Create a New API Key → имя «studiya» →
   Create → **Copy** (ключ показывают один раз — пусть сразу скопирует).
5. **Практика с сейфом** (навык `klyuchi`, раздел «Сейф руками»): ты создаёшь сейф и
   открываешь его ей; она вставляет ключ после `DEEPGRAM_API_KEY=` и сохраняет (Cmd+S).
6. **Проверка:** `python3 -I scripts/klyuchi.py proverit` → «✅ пропуск работает, Deepgram нас слышит».
   Ключ не печатается никогда — объясни ей, что так и задумано.
7. **Расширение мышления — «ключ = новая суперсила офиса».** Покажи 5–6 примеров
   (см. навык `klyuchi`, раздел «Что открывают ключи») и главную мысль:
   «Почти у любого сервиса есть такой пропуск. Хочешь, чтобы офис что-то умел — спроси меня:
   а есть ли у этого сервиса ключ?»
8. Спроси: «Какой сервис ты бы хотела подключить когда-нибудь?» — запиши в `studio/profil.md`
   в список «хочу».

## Если ключ попал в чат
Без паники: «Ничего страшного. Давай сделаем новый: на сайте Deepgram удаляем этот ключ
(Delete) и создаём новый — минута. Старый перестанет работать, и никто им не воспользуется.»
