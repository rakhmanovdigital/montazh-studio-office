# Монтаж ролика

Монтажный стол — `scripts/montazh.py` (рецепт JSON + паспорт стиля). Текст, субтитры и
графика рисуются через Chrome-слой (в FFmpeg из Homebrew нет модуля субтитров — так даже
красивее: любые шрифты и CSS).

## Ход

1. **Карточка на доске** (`studio/doska.md`) — если ролик для клиента. Без карточки не начинаем.
2. **Исходники** → `media/ishodniki/<клиент>/`. Посмотри их: `ffprobe`, пара кадров (ffmpeg → jpg → Read).
   Длинное видео с речью: `python3 -I scripts/titry.py <файл> --tolko-slova` → расшифровка
   по словам с временем — по ней выбираешь куски (хук, лучшие фразы, без оговорок и пауз;
   границы кусков — в паузах между словами, не посреди слова).
3. **Рецепт** `clients/<клиент>/recepty/R-NNN.json` по образцу `clients/_primer-recept.json`:
   куски (файл, с, по), заголовок-хук на первые 2–3 с, музыка (если есть), субтитры.
4. **Кадр-пробник:** `python3 -I scripts/montazh.py <рецепт> --probnik` → jpg → посмотри сам
   (Read), потом покажи ей: «Так будет выглядеть. Собираю целиком?» Без её «да» целиком не
   собираешь (если она заранее не сказала «собирай без пробника»).
5. **Весь ролик:** `python3 -I scripts/montazh.py <рецепт>` → `media/gotovo/<клиент>/R-NNN.mp4`.
6. **Самопроверка** (навык `nasmotrennost`, раздел «Самопроверка») + сверка с книгой правок
   `studio/pravki.md`. Не совпало — правишь и пересобираешь сам, до 3 кругов.
7. **Показ:** `open media/gotovo/<клиент>/R-NNN.mp4` + 1–2 строки, что сделано. Статус на доске → 👀.
8. **Её правки** → навык `pravki`.

## Чего нет в рецепте — дописываем код

Нужен приём, которого нет (тряска, вспышка, стоп-кадр, скорость, хромакей, стикер…) —
смотри `studio/slovar-capcut-ffmpeg.md`, добавь опцию в `scripts/montazh.py` (аккуратно,
в стиле файла), проверь на тестовом исходнике, потом на ролике. Так студия растёт.

## Проверка, что студия жива
`python3 -I scripts/montazh.py --test` → `media/gotovo/test/test.mp4` (3 с, заголовок + субтитры).
