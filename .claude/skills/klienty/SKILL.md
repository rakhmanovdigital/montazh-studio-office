# Клиенты и пакеты

## Новый клиент
1. Короткое имя латиницей для папок (`anna-fitnes`) — предложи сам, она подтверждает.
2. `clients/<клиент>/kartochka.md` по шаблону `clients/_klient-shablon.md` — спрашивай по
   одному вопросу: ниша, соцсети, пакет (роликов/мес, цена, сроки, правки), дата продления,
   стиль её словами (как делала в CapCut).
3. Строка в `studio/doska.md` → «Клиенты и пакеты».
4. Следующий шаг: «Кинь 2–4 готовых ролика этого клиента — соберу паспорт стиля» (навык `nasmotrennost`).

## Пакет месяца
- В начале месяца: на доске «Сдано в этом месяце» = 0 / N; ролики пакета — карточками Р-NNN.
- Ролик сдан (клиент принял) → +1, карточка в «Сдано».
- За 5 дней до даты продления — Директор напоминает ей одной строкой: «у <клиента> пакет
  кончается <дата>, сдано X из N. Напишем про продление?» Текст клиенту — черновиком, отправляет она.

## Сводка «что по клиентам»
≤6 строк: по каждому клиенту «сдано X/N · в работе · ближайший срок» + ❗ что ждёт её.

## Правило
Офис сам клиентам не пишет. Любой текст клиенту — черновик, она читает и отправляет сама.
