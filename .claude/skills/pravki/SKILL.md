# Правки

1. **Разложи** правки в нумерованный список конкретных действий с таймкодами:
   «0:03 — убрать слово „короче“ · 0:07 — субтитр крупнее · весь ролик — музыка тише».
   Непонятная правка («сделай поживее») → предложи 2 конкретных варианта, спроси её.
2. Покажи ей список: «Понял так: … — верно?» Подтвердила → правишь рецепт
   `clients/<клиент>/recepty/R-NNN.json` (или паспорт, если правка про стиль) и пересобираешь
   (навык `montazh`, без пробника, если правка мелкая).
3. **Запомни:** каждое правило — в `studio/pravki.md` (раздел клиента или «Общие») одной
   строкой + ей «записал правило: …». Правка про стиль клиента → сразу в его `pasport.json`.
   Вторая правка на ту же тему → правило в паспорт или в память сотрудника.
4. На доске: статус ✏️ → 👀 после пересборки. Круги правок считаем (в пакете их может быть ограниченно).
