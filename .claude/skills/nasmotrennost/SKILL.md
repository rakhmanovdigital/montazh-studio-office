# Насмотренность — стиль клиента из его роликов

Claude сам не «смотрит» видео — он видит картинки и цифры. Скрипт даёт ему «глаза во
времени»: цифры по 6 слоям + листы кадров. **Листы обязательно открыть и посмотреть** (Read),
иначе паспорт будет по цифрам без глаз.

## Ход

1. Ролики клиента → `media/primery/<клиент>/` (имя клиента латиницей, коротко: `anna-fitnes`).
2. Если в примерах есть речь — звук уйдёт в Deepgram для расшифровки (она согласилась на
   ступени 3). Не хочет — флаг `--bez-rechi`.
3. Разбор:
   `python3 -I scripts/nasmotrennost.py media/primery/<клиент>/*.mp4 --klient <клиент>`
   → `clients/<клиент>/nasmotrennost/razbor.md` + листы кадров + черновик `clients/<клиент>/pasport.json`
   (с блоком `etalon` — цифры, с которыми будем сверяться).
4. **Посмотри листы** каждого ролика:
   - `1_plany.jpg` — какие планы, крупность, композиция, есть ли повторяющиеся приёмы;
   - `2_perehody.jpg` — 5 кадров вокруг склейки: резкая (кадр сменился сразу) / растворение
     (полупрозрачное наложение) / шторка (сдвиг) / зум / вспышка (белый кадр);
   - `3_tekst_nachalo.jpg` — первые 3 с, 6 кадров/с: хук, как появляются субтитры
     (подсветка слова, всплытие, по одному), сколько слов на экране;
   - `4_krupno.jpg` — шрифт, цвет, обводка, плашка, где на экране текст.
5. **Допиши паспорт** `clients/<клиент>/pasport.json` по увиденному: `perehod.tip`, `zum`,
   `titry` (режим, слов, шрифт, цвета, положение 0…1 от верха, плашка), `cvet`, `zagolovok`.
   Переводи её CapCut-слова по словарю `studio/slovar-capcut-ffmpeg.md`.
   Опционально (если подключён Google и она сказала «да» на отправку): Gemini смотрит ролик
   целиком — `python3 -I scripts/gemini-smotret.py <ролик> --out clients/<клиент>/nasmotrennost/gemini.md`.
6. **Паспорт словами** — `clients/<клиент>/pasport-stilya.md`: 6–10 строк её языком
   («субтитры по 2 слова капсом, текущее слово жёлтое, склейка каждые ~1,2 с, в бит…»).
7. **Покажи ей и спроси:** «Вот как я понял стиль <клиента>. Верно? Что поправить?»
   Её поправки — в паспорт + в `studio/pravki.md`. Утвердила → в карточке клиента «паспорт ✅».

## Самопроверка готового ролика

`python3 -I scripts/nasmotrennost.py media/gotovo/<клиент>/R-001.mp4 --sravnit clients/<клиент>/pasport.json`
→ ✅/⚠️ по каждой цифре. Расхождение → правь рецепт или паспорт, пересобери, проверь снова
(до 3 кругов). Потом посмотри листы кадров нового ролика глазами — и только тогда показывай ей.

## Честная граница
Цифры не ловят «вайб». Последнее слово — за ней: она режиссёр, офис — монтажёр.
