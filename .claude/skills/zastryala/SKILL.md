# Застряла

1. **Сначала успокоить** (одна фраза): «Всё хорошо, так бывает у всех. Ничего не сломано
   насовсем — у нас есть снимок-страховка. Разберёмся.»
2. **Один вопрос диагностики** — самый полезный: «Что ты сделала перед этим?» или
   «Пришли скриншот того, что видишь» (Cmd+Shift+4 → выделить → перетащить сюда).
3. **Один шаг.** Не список из пяти. Ждёшь «сделала» → следующий.
4. **Сам проверь, что можешь:** `bash scripts/proverka.sh`, `git status`, последние ошибки скрипта.
5. Сломался файл офиса → покажи, что вернёшь, и верни из снимка:
   `git log --oneline -5` → `git restore --source=<снимок> <файл>`. Скажи ей, что вернул.
6. Не вышло за 3 шага → честно: «Это непривычная поломка. Давай запишем, что случилось,
   и спросим человека, который дал тебе офис» — и составь ей короткое сообщение с описанием
   (без ключей и личного).

Никогда: «это же просто», «ты что-то сделала не так», простыни терминов.
