# 🎬 Студия монтажа — офис на Claude Code

Офис для монтажёра коротких видео (рилсы, шортсы, тикток). Вместо кнопок в CapCut — словами:
офис сам режет, клеит, делает субтитры из речи, разбирает стиль клиента по его роликам
и монтирует новые ролики в этом стиле.

Внутри:
- **Господин Тимур** — учитель. С первой минуты, по шагам, от «что такое терминал» до своей
  студии. Ставит программы, объясняет ключи, безопасность, вайб-кодинг.
- **Директор** — после выпуска ведёт всю работу: клиенты, пакеты роликов на месяц, монтаж,
  правки, найм новых помощников.
- **Насмотренность** — кидаешь 2–4 ролика клиента, офис разбирает стиль (склейки, темп,
  переходы, субтитры, звук, цвет) и собирает паспорт стиля.
- **Монтаж кодом** — FFmpeg + Chrome-слой для красивого текста. Субтитры с подсветкой слова,
  зум-склейки, переходы, заголовки, музыка под голос, громкость как в соцсетях.
- **Разведчик** — кидаешь ссылку на рилс, офис делает раскадровку и говорит, что из этого
  можно взять себе.
- **Встроенная безопасность** — ключи в сейфе, опасные команды закрыты, снимок-страховка
  перед каждым днём, офис ничего не отправляет на GitHub.

Нужен **Mac** и **Claude Code** (приложение Claude → вкладка Code, или Claude Code в терминале).

## Как поставить

Открой Claude Code и напиши ему:

> Поставь мне офис студии монтажа: https://github.com/<автор>/montazh-studio-office

Дальше Claude всё сделает сам (инструкция для него — ниже). Потом открой папку
**«Студия монтажа»** на рабочем столе в Claude Code и напиши «привет» — встретит
Господин Тимур.

## Для Claude: как установить этот офис

Тебя попросили поставить офис по этой ссылке. Делай ровно это — и ничего сверх:

1. Проверь git: `git --version`. Если мак предлагает установить «инструменты разработчика» —
   скажи человеку нажать «Установить» в окне Apple и подождать (5–15 минут), потом продолжай.
2. Склонируй в папку на рабочем столе:
   `git clone https://github.com/<автор>/montazh-studio-office.git ~/Desktop/"Студия монтажа"`
3. Больше ничего не устанавливай и не запускай — программы ставит учитель внутри офиса,
   по одной и с согласия человека.
4. Скажи человеку простыми словами:
   «Готово! Офис лежит на рабочем столе в папке „Студия монтажа“. Теперь открой эту папку
   в Claude Code (в приложении: новая сессия → выбрать папку „Студия монтажа“) и напиши
   „привет“. Тебя встретит учитель — Господин Тимур.»
